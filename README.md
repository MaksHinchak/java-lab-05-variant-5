# Лабораторна робота №5 • Варіант 5

Колекції, Comparable, Comparator і множини

Автор: Гінчак Максим Богданович, 241-А.

## Завдання

- 1. Завантажити Ellipse та Hyperbola з окремих файлів у ArrayList відповідних типів; надрукувати, відсортувати через Collections.sort, додати по одному запису та повторно відсортувати.
- Створити ArrayList<Function>, відсортувати зовнішнім Comparator і записати у файл.
- 2. Через HashSet<Integer> реалізувати перетин і об’єднання цілих чисел.

## Запуск в IntelliJ IDEA

Відкрийте **саме цю папку Lab05** через File → Open → New Window. Це самостійний проєкт, який не потребує сусідніх лабораторних. Оберіть JDK 17+ у File → Project Structure → Project SDK. На підготовленому Mac вже налаштовано `JBR-25-labs`.

У списку конфігурацій виберіть `Lab05_Main` і натисніть Run. Робоча тека - корінь цього проєкту.

## Запуск у терміналі

```sh
./run.sh
./test.sh
```

Скрипти беруть JDK із JAVA_HOME, установленої IntelliJ або PATH. Для Windows: створіть папку out, виконайте `javac -encoding UTF-8 --release 17 -d out src/*.java`, потім `java -cp out Main` (у PowerShell перелік файлів можна передати через `Get-ChildItem src -Filter *.java`).

## Демонстрація

1. Прочитай data/ellipses.txt і data/hyperbolas.txt. Додай (1,2) та (2,2), збережи result.txt: 8 записів, перший Ellipse 1.0 2.0.
2. Покажи три стани списків: прочитані, відсортовані, після вставлення.
3. Множини: A=1 2 2, B=2 3. Перетин [2], об’єднання [1,2,3].
4. Порожній рядок задає порожню множину.
